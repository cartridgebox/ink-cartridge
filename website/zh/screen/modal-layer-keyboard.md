# 模态层键盘事件

模态层阶段是键盘流水线的第一站：先于全局键、普通图层和屏幕栈处理事件。规则有三条：

1. 只有 `zIndex` 最高的模态层接收键盘事件。
2. 顶层模态层把事件广播给内部所有激活元素。
3. 未被顶层模态层处理的按键被屏障吞掉，不再向下传递。

## 顶层独占

同时打开多个模态层时，只有最顶的一个参与分发；其余模态层保持挂载但不接收事件。顶层关闭后，下一个接管。

```ts
openModalLayer('modal-1', 100)
openModalLayer('modal-2', 200)   // 只有它接收键盘
```

`modal-2` 不处理的键不会给 `modal-1`，而是被屏障吞掉。

## 键盘屏障

普通图层未命中会继续冒泡，最后落到屏幕栈。模态层相反：只要还有模态层打开，未处理的键就停在最顶层模态层，不会到达下方普通图层或屏幕。

```tsx
function Dialog() {
  const { boundKeyboard } = useKeyboard()

  useEffect(() => boundKeyboard('return', () => confirm()), [boundKeyboard])
}
```

`return` 被对话框处理；其他键被屏障吞掉，屏幕上的绑定不会触发。

## 层内广播

顶层模态层内部与普通图层一致：事件广播给所有激活元素，多个元素可以同时响应同一个键。某个元素处理后，屏障仍然阻止事件继续下传。

## 放行与监听

- [`allowModal`](/zh/screen/allow-modal)：把指定键加入放行名单，模态层未处理时穿过屏障。
- [`useModalMissListener`](/zh/screen/modal-miss-listener)：在模态层内监听被屏障吞掉的键。

两者都不改变「模态层先处理」的顺序。

## 边界

- 模态层阶段先于全局键；需要在模态层打开时仍生效的全局快捷键，用 `allowModal` 放行。
- 没有任何激活元素的模态层仍然有屏障。
- `zIndex` 相同时按 `createdAt` 排序，后打开的在上。
- 模态层关闭后，键盘交还给下一个模态层；全部关闭后回到普通图层与屏幕栈。
